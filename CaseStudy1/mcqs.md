
# Git and GitHub — Beginner MCQs

**Case Study 01: Basic Git and GitHub Commands**

**Difficulty:** Beginner  
**Total Questions:** 10  
**Topics:** Git basics, repositories, staging, commits, and GitHub commands

## Questions

### Q1. What is Git?

A. A programming language  
B. A version control system  
C. A database management system  
D. A web browser  

### Q2. What is GitHub?

A. A code editor  
B. An operating system  
C. An online platform for hosting Git repositories  
D. A programming language  

### Q3. Which command initializes a new Git repository?

A. `git start`  
B. `git init`  
C. `git create`  
D. `git open`  

### Q4. Which command displays the current status of files in a repository?

A. `git log`  
B. `git show`  
C. `git status`  
D. `git check`  

### Q5. What is the purpose of `git add notes.txt`?

A. It deletes the file  
B. It uploads the file to GitHub  
C. It stages changes to the file  
D. It creates a new repository  

### Q6. Which command records staged changes in the local repository?

A. `git push`  
B. `git commit -m "message"`  
C. `git add`  
D. `git clone`  

### Q7. Which command displays the commit history?

A. `git status`  
B. `git init`  
C. `git log`  
D. `git remote`  

### Q8. Which command downloads a copy of an existing remote repository?

A. `git clone URL`  
B. `git init URL`  
C. `git push URL`  
D. `git add URL`  

### Q9. What does `git push` do?

A. Creates a local repository  
B. Stages files  
C. Uploads local commits to a remote repository  
D. Displays commit history  

### Q10. What is the main difference between `git add` and `git commit`?

A. Both commands perform exactly the same task  
B. `git add` stages changes, while `git commit` records staged changes  
C. `git add` uploads files, while `git commit` downloads files  
D. `git add` creates branches, while `git commit` deletes branches

## Learning Outcome

After completing this quiz, you should be able to:

- Explain the difference between Git and GitHub.
- Identify the purpose of basic Git commands.
- Understand staging and committing.
- Recognize how repositories are cloned and updated.
